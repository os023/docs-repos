# OpenCode 文档

[OpenCode](https://opencode.ai/) 是开源的 AI 编程助手，提供终端 TUI、桌面应用与 IDE 扩展等多种形态，用于在本地项目中提问、规划、改代码与协作分享。

本目录用于整理 **OpenCode 的中文安装、配置与使用笔记**，章节结构对照 [OpenCode 官方文档](https://opencode.ai/docs)。

## 文档导航

| 章节 | 说明 |
|------|------|
| [概览](overview) | 产品定位、终端/桌面/IDE、先决条件与阅读路径 |
| [安装](setup) | 安装脚本、包管理器、Windows 与 Docker 等获取方式 |
| [配置](config) | `/connect`、OpenCode Zen 与各 LLM 提供商 API Key |
| [初始化](init) | 进入项目、启动 TUI、`/init` 与 `AGENTS.md` |
| [使用指南](usage) | 提问、Plan/Build 模式、改代码、`/undo` 与 `/redo` |
| [分享](share) | `/share` 生成对话链接与团队协作 |
| [定制](customize) | 主题、快捷键、格式化器、自定义命令与配置文件 |

## 推荐阅读路径

1. **[概览](overview)** — 确认终端环境与 API Key 等先决条件。
2. **[安装](setup)** — 在本地安装 `opencode` 可执行文件。
3. **[配置](config)** — 通过 `/connect` 绑定 OpenCode Zen 或其他 LLM 提供商。
4. **[初始化](init)** — 在项目目录运行 `opencode` 并执行 `/init` 生成 `AGENTS.md`。
5. **[使用指南](usage)** — 按 Plan → Build 流程完成功能开发或日常问答。
6. 按需阅读 **[分享](share)** 与 **[定制](customize)**。
