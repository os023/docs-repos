# 安装

本节说明如何在公网服务器与内网机器上部署 **frps**（服务端）与 **frpc**（客户端），并完成首次启动与连通性自检。内容以中文笔记为主，细节以 [frp 官方文档 · 安装](https://gofrp.org/zh-cn/docs/setup/) 为准。

## 部署角色速览

| 组件 | 典型位置 | 作用 |
|------|----------|------|
| **frps** | 拥有公网 IP 的服务器 | 接收外部连接，按配置转发到对应 frpc |
| **frpc** | 内网服务所在机器 | 与 frps 建立控制连接，注册代理并转发本地端口或 HTTP 服务 |

二者可安装在不同操作系统上（例如 frps 在 Linux 云主机、frpc 在 Windows 办公机），只要网络可达且版本兼容即可。

## 配置文件格式

当前推荐使用 **TOML**（亦支持 YAML、JSON）；旧版 INI 仍可用，但新项目不建议采用。配置文件路径通过启动参数 `-c` 指定，无固定的系统默认路径，见 [快速开始与自检](quickstart#配置文件路径)。
