# 概览

本节汇总 frp 的定位与能力边界，便于在动手安装前先建立整体认识。内容结构对照 [官方文档 · 概览](https://gofrp.org/zh-cn/docs/overview/)。

## frp 是什么？

frp（Fast Reverse Proxy）是一款面向内网穿透场景的高性能反向代理。它支持 TCP、UDP、HTTP、HTTPS 等多种协议，并可在具备公网 IP 的节点上中转流量，使位于 NAT 或防火墙后的内网服务可被外部访问。

## 主要特性（择要）

- **多协议**：客户端与服务端之间可选用 TCP、QUIC、KCP、WebSocket 等传输方式。
- **连接复用**：在单条连接上承载多个会话，降低握手开销。
- **负载均衡与端口复用**：同一服务端端口可暴露多个内网服务（视代理类型而定）。
- **P2P（XTCP 等）**：部分场景下流量可不经服务器中转。
- **插件与 Web UI**：客户端/服务端插件扩展能力强，并配有管理界面。
