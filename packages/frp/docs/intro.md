# frp 文档

frp（Fast Reverse Proxy）是一款高性能反向代理，用于将处于 NAT 或防火墙后的本地服务暴露到公网。

本目录用于整理 **frp 的中文安装、配置与使用笔记**，章节结构对照 [frp 官方中文文档](https://gofrp.org/zh-cn/docs/)。
