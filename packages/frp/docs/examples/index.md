# 示例

本节索引常见穿透场景的配置思路。各场景的完整最小配置与注意事项将在后续章节单独成页；官方示例集见 [示例](https://gofrp.org/zh-cn/docs/examples/)。

## 计划覆盖的场景

| 场景 | 代理类型（常见） | 说明 |
|------|------------------|------|
| **SSH 访问内网机器** | TCP | 将内网 22 端口映射到 frps 某端口 |
| **HTTP / Web 内网服务** | HTTP | 通过子域名或自定义域名访问内网站点 |
| **HTTPS 或自定义域名** | HTTPS / HTTP + 插件 | 对外提供 TLS 或 Host 路由 |
| **安全暴露（STCP 等）** | STCP | 仅授权用户可连的内网服务 |
| **点对点（XTCP）** | XTCP | 降低中转带宽占用 |

## 阅读建议

1. 先完成 [安装](../setup) 与 [快速开始与自检](../setup/quickstart)，确认 frpc 已在 frps 上线。
2. 在 [概念](../concepts) 中确认代理类型与端口/域名需求。
3. 从与本节目录对应的子页面复制最小配置，再按环境修改 `serverAddr`、`remotePort`、域名等字段。
