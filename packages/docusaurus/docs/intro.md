# Docusaurus 文档

Docusaurus 是 Meta 开源的静态网站生成器，专为技术文档、博客与版本化文档设计。

本仓库主站即基于 Docusaurus；各库的文档以 **pnpm workspace 子包** 形式组织，由主站聚合。
