# Prisma 文档

Prisma 是面向 Node.js 与 TypeScript 的现代 ORM，提供类型安全的数据库访问、Schema 建模与迁移工具。

本目录用于整理 **Prisma 相关的中文笔记与翻译**，可按主题继续拆分章节。
